# Reagowanie na incydent

**Stan: procedura bazowa, bez aktywnego dyżuru.**

Po wykryciu podejrzenia podatności, kompromitacji paczki lub wycieku danych zabezpiecz minimalne dowody, ustal SHA, wersję, dotkniętych odbiorców oraz zakres. Nie publikuj sekretów w Issues i nie zmieniaj uprzywilejowanych hostów lub cudzych uprawnień bez zgody.

Uprawniony właściciel ustala odwracalne ograniczenie skutków, potrzebę wycofania release, zmianę credentiali, sposób powiadomienia konsumentów oraz regresję na dokładnym SHA. Dokumentuj wynik faktycznie wykonanych czynności i ryzyko rezydualne.

Kanał zgłoszeń i zasady prywatności: [SECURITY.md](../../SECURITY.md).
