# Rejestr decyzji architektonicznych (ADR)

ADR zapisują **dlaczego** wybrano rozwiązanie, jego alternatywy i konsekwencje. Nie zastępują kontraktu API, kodu ani testów.

| ADR | Zakres | Status |
| --- | --- | --- |
| [0001](0001-contract.md) | Kanoniczne źródło API i kodu | proposed |
| [0002](0002-security-boundaries.md) | Granice zaufania | proposed |
| [0003](0003-supply-chain.md) | Zależności i pochodzenie wydania | proposed |

Nowy ADR zawiera datę, status `proposed/accepted/rejected/superseded`, kontekst, decyzję lub propozycję, alternatywy, konsekwencje, dowody i linki. `proposed` nie jest autoryzacją wdrożenia. Zmiana zaakceptowanego ADR wymaga następnego rekordu i odnośnika do zastępowanego.

Limit objętości: [standard](../documentation.md).
