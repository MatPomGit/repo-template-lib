# ADR-0001: kanoniczny właściciel komponentu

Status: proposed

Decyzja: repozytorium przechowuje oryginalny kod oraz aktualne publiczne kontrakty. Repozytoria manuskryptowe odwołują się do niego przez wersjonowane zależności.

Konsekwencje: brak dublowania kodu, konieczność kontroli kompatybilności i niezmiennych wydań.
