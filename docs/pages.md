# Strona GitHub Pages

Opcjonalnie publikuj dokumentację komponentu z `docs/` za pomocą MkDocs.
Przy prywatnym repo strona Pages może być publiczna: weryfikuj listę plików budowania przed wdrożeniem.
Nie wdrażaj Pages workflow przez szablon bez potwierdzenia polityki kosztów i uprawnień.
Strona projektu `msc-*` jest odrębna od dokumentacji narzędzia.
